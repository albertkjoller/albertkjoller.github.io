Deep neural networks typically have far more parameters than there are observations to train on -- they are *overparameterized*. As a consequence, many different settings of the network's parameters fit the training data equally well, while (mostly) disagreeing away from it. Such disagreement reflects *uncertainty* about the model's predictions.

There is no general way to write down all these parameter settings directly, and finding them in practice is also not straightforward: training the network many times is computationally expensive, and cheaper approaches that start from a single trained model rarely end up at parameter settings that fit the data exactly. This note describes $\text{DiMS}$, a method for generating many models that agree on the training data but disagree elsewhere, starting from a single trained network. $\text{DiMS}$ builds on complicated theory from Riemannian geometry and classical mechanics, but we have tried to keep the note intuitive by using the analogy of a rolling ball throughout.

All figures in the note are interactive and illustrate the methods on a small toy problem with two parameters. For the full details, we encourage you to check out the paper *"Don't Stop Me Yet: Sampling Loss Minima via Dissipative Riemannian Mechanics"* <d-cite key="jacobsen2026dims"></d-cite>.

## Same function, different parameters

Informally, a neural network is a function $f_{\boldsymbol{\theta}}(\boldsymbol{x})$ whose behaviour is set by its *parameters* $\boldsymbol{\theta} \in \Theta \subseteq \mathbb{R}^K$ -- i.e. its weights and biases. Training the network means minimizing a loss $\mathcal{L}(\boldsymbol{\theta}; \mathcal{D})$ over a dataset $\mathcal{D} = \\{(\boldsymbol{x}\_n, y\_n)\\}\_{n=1}^{N}$,

\begin{equation\*}
  \boldsymbol{\theta}^\ast = \arg \min_{\boldsymbol{\theta}} \mathcal{L}(\boldsymbol{\theta}; \mathcal{D}),
\end{equation\*}

which is typically done with gradient descent. Gradient descent has a simple physical picture, which we will build on throughout the note: the loss defines a landscape -- the *loss surface* -- and training then corresponds to rolling a ball downhill from a random starting point until it comes to rest at a minimum. Press "Drop a ball" in the figure to see this.

For overparameterized networks where $K \gg N$, the minimum is typically not a single point $\boldsymbol{\theta}^\ast$, and instead a whole continuum of parameters fits the data equally well<d-cite key="izmailov2018loss"></d-cite>. Throughout the note we use a very simple example of this: one training point $(x, y) = (1, 1)$, a two-parameter "network", $f_{\boldsymbol{\theta}}(x) = \theta_1 \theta_2\, x$, and the mean-squared error (MSE) loss

\begin{equation\*}
  \mathcal{L}(\boldsymbol{\theta}; \mathcal{D}) = \frac{(f_{\boldsymbol{\theta}}(x) - y)^2}{2} = \frac{(\theta_1 \theta_2 - 1)^2}{2}.
\end{equation\*}

Every parameter pair with $\theta\_1\theta\_2 = 1$ fits the data point perfectly -- scaling one parameter up and the other down by the same factor, $(\theta\_1, \theta\_2) \mapsto (c\,\theta\_1, \theta\_2 / c)$, so never changes the fit. These pairs form the *set of minima* (dashed in the figure) which are all equally good solutions to the optimization problem.

In a real network such minima often disagree away from the data, and using them together is one way to quantify the model's uncertainty. The most direct approach is a *deep ensemble*<d-cite key="lakshminarayanan2017simple"></d-cite>: train the network several times from different initializations, average the predictions of the resulting models, and use their spread as a measure of uncertainty. It works well, but every ensemble member costs a full training run.

Note that in this toy problem, all parameters on the set of minima give exactly the same function for every input, so it cannot illustrate this predictive uncertainty itself. We simply use it because it allows us to show *how* different uncertainty quantification methods behave in parameter spaces of overparameterized networks.


<details>
<summary>Formally: the set of minima</summary>

<p>The parameters that give exactly the same output as $\boldsymbol{\theta}^\ast$ on every training input form the <em>set of reparameterization-invariant solutions</em><d-cite key="roy2024reparameterization"></d-cite>,</p>

$$
\mathcal{R}_\mathcal{D}(\boldsymbol{\theta}^\ast) = \{\boldsymbol{\theta} \in \Theta : f_{\boldsymbol{\theta}}(\boldsymbol{x}) = f_{\boldsymbol{\theta}^\ast}(\boldsymbol{x}), \;\; \forall \boldsymbol{x} \in \mathcal{D}\}.
$$

<p>A looser notion, which only asks for parameter settings achieving the locally lowest loss, is the <em>set of minima</em>. Writing $\mathcal{B}_k$ for the basin of attraction of the $k$'th local minimum and $\mathcal{L}^\ast_k(\mathcal{D})$ for its loss, it is the disjoint union</p>

$$
  \mathcal{S}_\ast(\mathcal{D}) = \bigsqcup_{k\in \mathcal{K}} \{\boldsymbol{\theta} \in \mathcal{B}_k : \mathcal{L}(\boldsymbol{\theta}) = \mathcal{L}^\ast_k(\mathcal{D})\}.
$$

<p>Computing this set explicitly is out of reach for real networks, but it is the object we would like to explore. In our toy problem it is the two curves $\theta_1\theta_2 = 1$, and the two notions here coincide, i.e. $\mathcal{S}_{\ast}(\mathcal{D}) = \mathcal{R}_\mathcal{D}(\boldsymbol{\theta}^\ast)$.</p>

## The Laplace approximation

Retraining the network for every ensemble member is expensive, so a popular alternative is the *Laplace approximation*<d-cite key="laplace1774,mackay1992bayesian,daxberger2021laplace"></d-cite>, which needs only a single trained model and works as follows:

  1. train one model to get $\boldsymbol{\theta}^\ast$,
  2. fit a Gaussian around $\boldsymbol{\theta}^\ast$ according to the local curvature of the loss,
  3. sample parameters from that Gaussian to form the ensemble.

The idea is to pretend that, close to $\boldsymbol{\theta}^\ast$, the loss is a bowl. In directions where the bowl is steep, the Gaussian gets a small spread, since moving that way quickly ruins the fit. In directions where the loss is flat, it gets a large spread. Mathematically, the Laplace approximation is defined as

$$
  q(\boldsymbol{\theta}) = \mathcal{N}(\boldsymbol{\theta}\mid\boldsymbol{\theta}^\ast, \mathbf{\Sigma}) \qquad \text{with} \qquad \mathbf{\Sigma} = \big(\mathbf{H}(\boldsymbol{\theta}^\ast) + \lambda\mathbb{I}_K\big)^{-1},
$$

where $\mathbf{H}(\boldsymbol{\theta}^\ast)$ is the Hessian of the loss at $\boldsymbol{\theta}^\ast$ and $\lambda > 0$ is a small constant that keeps the matrix invertible. Equivalently, one can draw an offset $\tilde{\boldsymbol{v}} \sim \mathcal{N}(\boldsymbol{0}, \mathbf{\Sigma})$ and take a straight step from the trained model, $\boldsymbol{\theta} = \boldsymbol{\theta}^\ast + \tilde{\boldsymbol{v}}$. This view will be useful later, since the methods that follow use the same vector $\tilde{\boldsymbol{v}}$, but as a direction to start moving in rather than a fixed offset.

Press "Sample" in the figure to draw an ensemble this way. The Gaussian is stretched along the tangent of the set of minima at $\boldsymbol{\theta}^\ast$ -- the flat direction -- and is about three times wider along it than across it. Close to the trained model it therefore follows the set of minima well, but further away the Laplace approximation parts ways from the set of minima. Since the Gaussian is a straight ellipse while the set of minima is curved, most samples land *next to* the set rather than on it. A fixed shape placed at a single point cannot follow a curved set of minima.

<details>
<summary>The Laplace approximation</summary>

<p>The Laplace approximation was born as an approximation to a Bayesian posterior. Bayes' theorem combines prior information $p(\boldsymbol{\theta})$ about the parameters with the likelihood $p(\mathcal{D} \mid \boldsymbol{\theta})$ of the observed data to form the posterior</p>

$$
  p(\boldsymbol{\theta} \mid \mathcal{D}) = \frac{p(\mathcal{D} \mid \boldsymbol{\theta})\, p(\boldsymbol{\theta})}{p(\mathcal{D})}, \qquad p(\mathcal{D}) = \int p(\mathcal{D} \mid \boldsymbol{\theta})\, p(\boldsymbol{\theta})\, \mathrm{d}\boldsymbol{\theta}.
$$

<p>For a neural network the normalizing term, $p(\mathcal{D})$, is intractable, which is why approximation methods exist.</p>

<p>In the setting explained so far, we form the Laplace approximation for a loss function that is not necessarily coming from a likelihood. <em>Generalized Bayes</em><d-cite key="bissiri2016general"></d-cite> allows us to define the generalized (or Gibbs) posterior from any loss function as</p>

$$
  \pi(\boldsymbol{\theta}) \propto \exp\big(-\mathcal{L}(\boldsymbol{\theta})\big).
$$

<p>In the original formulation, the generalized posterior combines a prior with an exponentiated loss scaled by a learning rate. Here, we absorb both the prior and the learning rate into $\mathcal{L}$.</p>

<p>Standard Bayes is then the special case where the loss is the negative log-joint, $\mathcal{L}(\boldsymbol{\theta}) = -\log p(\mathcal{D} \mid \boldsymbol{\theta}) - \log p(\boldsymbol{\theta})$, and several well-known loss constructions can be phrased as such: the MSE loss corresponds to a Gaussian likelihood, and weight decay to a Gaussian prior. The Laplace approximation is a Gaussian approximation of $\pi$, whichever of the two readings one prefers.</p>

<p>Let $\boldsymbol{\theta}^\ast$ be a minimizer of $\mathcal{L}$. A second-order Taylor expansion around it, with $\boldsymbol{\theta} = \boldsymbol{\theta}^\ast + \boldsymbol{\delta}$, gives</p>

$$
  \mathcal{L}(\boldsymbol{\theta}^\ast + \boldsymbol{\delta}) \approx \mathcal{L}(\boldsymbol{\theta}^\ast) + \boldsymbol{\delta}^\top \underbrace{\nabla_{\boldsymbol{\theta}} \mathcal{L}(\boldsymbol{\theta}^\ast)}_{=\,\boldsymbol{0}} + \frac{1}{2}\boldsymbol{\delta}^\top \mathbf{H}(\boldsymbol{\theta}^\ast) \boldsymbol{\delta}, 
$$

<p> where $\mathbf{H}(\boldsymbol{\theta}^\ast):= \nabla_{\boldsymbol{\theta}}^2 \mathcal{L}(\boldsymbol{\theta}^\ast)$, and the linear term vanishes because the gradient is zero at a minimum. In other words, the loss is locally a bowl. Plugging this into $\pi$,</p>

$$
  \begin{aligned}
  \pi(\boldsymbol{\theta}^\ast + \boldsymbol{\delta}) &\propto \exp\big(-\mathcal{L}(\boldsymbol{\theta}^\ast)\big)\, \exp\Big(-\tfrac{1}{2}\boldsymbol{\delta}^\top \mathbf{H}(\boldsymbol{\theta}^\ast) \boldsymbol{\delta}\Big) \\
  &\propto \exp\Big(-\tfrac{1}{2}\boldsymbol{\delta}^\top \mathbf{H}(\boldsymbol{\theta}^\ast) \boldsymbol{\delta}\Big),
  \end{aligned}
$$

<p>which is exactly the (unnormalized) density of a Gaussian in $\boldsymbol{\delta}$ with mean $\boldsymbol{0}$ and precision $\mathbf{H}(\boldsymbol{\theta}^\ast)$. Shifting back to $\boldsymbol{\theta}$ and normalizing the distribution gives the Laplace approximation</p>

$$
  q(\boldsymbol{\theta}) = \mathcal{N}\big(\boldsymbol{\theta} \mid \boldsymbol{\theta}^\ast, \mathbf{H}(\boldsymbol{\theta}^\ast)^{-1}\big).
$$

<p>The trained model is the mean, and the curvature sets the spread: directions in which the loss rises steeply get a small variance, and flat directions a large one.</p>

<p><strong>The catch: the Hessian is singular on the set of minima.</strong> Moving along the set of minima does not change the loss, so the curvature in that direction is zero and $\mathbf{H}(\boldsymbol{\theta})$ cannot be inverted. In our toy problem, when $\theta_1\theta_2 = 1$,</p>

$$
  \mathbf{H}(\boldsymbol{\theta}) = \begin{pmatrix} \theta_2^2 & 2\theta_1\theta_2 - 1 \\ 2\theta_1\theta_2 - 1 & \theta_1^2 \end{pmatrix} = \begin{pmatrix} \theta_2^2 & 1 \\ 1 & \theta_1^2 \end{pmatrix},
$$

<p>which has determinant $\theta_1^2\theta_2^2 - 1 = 0$, and in practice one therefore adds a small regularizing constant to the diagonal, $\lambda > 0$. This corresponds to adding the term $\tfrac{\lambda}{2}\lVert\boldsymbol{\theta}\rVert^2$ in the loss, which additionally has the interpretation of being a Gaussian prior $\mathcal{N}(\boldsymbol{0}, \lambda^{-1}\mathbb{I}_K)$ on the parameters.</p>

<p>For neural networks, the Hessian is usually replaced by the generalized Gauss–Newton matrix, which is positive semi-definite and cheaper to compute<d-cite key="daxberger2021laplace"></d-cite>. Either way, the approximation is a single fixed ellipse around $\boldsymbol{\theta}^\ast$, and along the set of minima its width is set only by $\lambda$, while it remains straight where the set of minima curves.</p>

</details>

## Following the shape of the loss

Though the Laplace approximation indeed does use information about the loss surface -- namely its curvature at $\boldsymbol{\theta}^\ast$ -- it is defined in the flat parameter space $\Theta$, where the shortest path between two points is a straight line. Its samples are therefore straight-line offsets from $\boldsymbol{\theta}^\ast$, no matter how the loss surface actually bends.

The floor in the figure is the parameter space $\Theta = \mathbb{R}^K$ with the usual Euclidean way of measuring distances. The surface above it is described by the embedding

$$
  h(\boldsymbol{\theta}) = \big(\theta_1, \dots, \theta_K, \mathcal{L}(\boldsymbol{\theta})\big) \in \mathbb{R}^{K+1},
$$

which lifts every parameter $\boldsymbol{\theta}$ on the floor to exactly one point on the surface. The loss surface $h(\Theta)$ is therefore a $K$-dimensional curved surface living in $K+1$ dimensions -- a so-called *embedded submanifold*<d-cite key="jacobsen2025monge"></d-cite>.

<aside>
<strong>Two manifolds.</strong> The set of minima can be a manifold too, with fewer dimensions than the loss surface. This is the case when the stacked Jacobian of the network's outputs on all training data has the same rank $r$ in a neighbourhood of the set of minima, which then has dimension $K - r$. In our toy problem, $K = 2$ and $r = 1$, so the set of minima is a curve. To distinguish between these manifolds, we call one "the loss surface" and the other "the set of minima".
</aside>

The key idea is to let the parameter space *inherit* its notion of distance from the loss surface, which is formally known as *pullback geometry*: a step on the floor is measured by how long it is on the surface above it. Concretely, an infinitesimally small step $\boldsymbol{\delta}$ on the floor locally moves the lifted point by $\mathbf{J}\_h(\boldsymbol{\theta})\,\boldsymbol{\delta},$ where $\mathbf{J}\_h = \big\[\mathbb{I}_K, \nabla\_{\boldsymbol{\theta}} \mathcal{L}(\boldsymbol{\theta}) \big\]^\top$ is the Jacobian of the embedding. In words, the lifted point moves by the same step sideways, plus the change in loss it causes, $\nabla\_{\boldsymbol{\theta}}\mathcal{L}(\boldsymbol{\theta})^\top\boldsymbol{\delta}$, upwards. The squared length of this lifted step is $\boldsymbol{\delta}^\top \mathbf{G}(\boldsymbol{\theta})\, \boldsymbol{\delta}$, where the matrix

$$
  \mathbf{G}(\boldsymbol{\theta}) = \mathbf{J}_h(\boldsymbol{\theta})^\top \mathbf{J}_h(\boldsymbol{\theta}) = \mathbb{I}_K + \nabla_{\boldsymbol{\theta}}\mathcal{L}(\boldsymbol{\theta})\, \nabla_{\boldsymbol{\theta}}\mathcal{L}(\boldsymbol{\theta})^\top
$$

is called the *metric*. It defines the inner product, and thereby lengths and angles, on the loss surface, expressed in the parameters $\boldsymbol{\theta}$.

The ellipses on the floor of the figure show what this means. Each one contains the steps from its centre that have the same length when measured on the surface. Where the loss is flat, i.e. where $\nabla\_{\boldsymbol{\theta}}\mathcal{L}(\boldsymbol{\theta})=\boldsymbol{0}$, the metric $\mathbf{G}(\boldsymbol{\theta})$ is the identity and the ellipses are circles. Where the loss is steep, the ellipses are squeezed in the uphill direction, since a step up a wall is longer on the surface than its shadow on the floor.

Equipped with this metric, the parameter space becomes a *Riemannian manifold*, provided that the loss is smooth, which also requires a smooth network, e.g. through smooth activation functions. This means that we can do all calculations directly in the parameters $\boldsymbol{\theta}$, without ever working on the loss surface itself, while lengths, speeds and straight lines are still measured as if we were moving on the loss surface. The gradient that respects this geometry is the *Riemannian gradient*, 

$$
  \operatorname{grad}\mathcal{L}(\boldsymbol{\theta}) := \mathbf{G}(\boldsymbol{\theta})^{-1}\nabla_{\boldsymbol{\theta}}\mathcal{L}(\boldsymbol{\theta}) = \frac{\nabla_{\boldsymbol{\theta}}\mathcal{L}(\boldsymbol{\theta})}{1 + \lVert\nabla_{\boldsymbol{\theta}}\mathcal{L}(\boldsymbol{\theta})\rVert^2},
$$

an ordinary gradient that is shortened on steep walls.

<details>
<summary>The loss surface as a Riemannian manifold</summary>

<p>To keep the notation light, we write $\nabla\mathcal{L}$ for the gradient $\nabla_{\boldsymbol{\theta}}\mathcal{L}(\boldsymbol{\theta})$ and drop the dependence on $\boldsymbol{\theta}$ where it is clear. The loss surface is the set</p>

$$
  \mathcal{M} = \{h(\boldsymbol{\theta}) \mid \boldsymbol{\theta} \in \Theta\} \subseteq \mathbb{R}^{K+1}, \qquad h(\boldsymbol{\theta}) = \big(\theta_1, \dots, \theta_K, \mathcal{L}(\boldsymbol{\theta})\big),
$$

<p>which is a smooth $K$-dimensional submanifold of $\mathbb{R}^{K+1}$ when the loss is smooth.</p>

<p><strong>Tangent vectors.</strong> The columns of the Jacobian</p>

$$
  \mathbf{J}_h = \begin{bmatrix} \mathbb{I}_K \\ \nabla\mathcal{L}^\top \end{bmatrix} \in \mathbb{R}^{(K+1) \times K}
$$

<p>span the tangent space $T_{\boldsymbol{p}}\mathcal{M}$ at $\boldsymbol{p} = h(\boldsymbol{\theta})$. Every tangent vector can therefore be written as $\boldsymbol{v} = \mathbf{J}_h\tilde{\boldsymbol{v}}$, with parameter-space coordinates $\tilde{\boldsymbol{v}} \in T_{\boldsymbol{\theta}}\Theta$.</p>

<p><strong>The metric.</strong> The metric tensor $g_{\boldsymbol{p}}$ is the Euclidean inner product of $\mathbb{R}^{K+1}$ restricted to $T_{\boldsymbol{p}}\mathcal{M}$. In parameter-space coordinates it reads</p>

$$
  g_{\boldsymbol{p}}(\boldsymbol{v}_1, \boldsymbol{v}_2) = \boldsymbol{v}_1^\top \boldsymbol{v}_2 = \tilde{\boldsymbol{v}}_1^\top \mathbf{J}_h^\top \mathbf{J}_h \tilde{\boldsymbol{v}}_2 = \tilde{\boldsymbol{v}}_1^\top \mathbf{G}\, \tilde{\boldsymbol{v}}_2,
$$

<p>with the metric matrix</p>

$$
  \mathbf{G} = \mathbf{J}_h^\top \mathbf{J}_h = \mathbb{I}_K + \nabla\mathcal{L}\, \nabla\mathcal{L}^\top.
$$

<p>This is the <em>pullback metric</em>: the inner product on the surface, pulled back to the parameter space and represented there by $\mathbf{G}$. Due to its form as an identity matrix plus a positive semi-definite matrix, $\mathbf{G}$ is positive definite everywhere, and it varies smoothly with $\boldsymbol{\theta}$ when the loss is smooth. Hence $(\mathcal{M}, g)$ is a Riemannian manifold, and all geometric computations on $\mathcal{M}$ can be carried out directly in the parameter space $\Theta$ by using $\mathbf{G}$.</p>

<p><strong>The ellipses in the figure</strong> are the <em>indicatrices</em> of the metric, i.e. the parameter-space coordinates of the tangent vectors of length $R$, $\{\tilde{\boldsymbol{v}} : \tilde{\boldsymbol{v}}^\top \mathbf{G}\, \tilde{\boldsymbol{v}} = R^2\}$. The matrix $\mathbf{G}$ has eigenvalue $1 + \lVert\nabla\mathcal{L}\rVert^2$ in the direction of the gradient and $1$ in all directions orthogonal to it. Each ellipse therefore has radius $R$ along the level set and the smaller radius $R / \sqrt{1 + \lVert\nabla\mathcal{L}\rVert^2}$ in the uphill direction.</p>

<p><strong>Cheap to compute.</strong> The metric is a rank-one update of the identity, so the Sherman–Morrison formula gives its inverse in closed form, and with it the <em>Riemannian gradient</em>,</p>

$$
  \mathbf{G}^{-1} = \mathbb{I}_K - \frac{\nabla\mathcal{L}\, \nabla\mathcal{L}^\top}{1 + \lVert \nabla\mathcal{L} \rVert^2}, \qquad \operatorname{grad}\mathcal{L} := \mathbf{G}^{-1}\nabla\mathcal{L} = \frac{\nabla\mathcal{L}}{1 + \lVert \nabla\mathcal{L} \rVert^2}.
$$

<p>Neither requires forming a $K \times K$ matrix, so both stay cheap even with millions of parameters.</p>

</details>

## Geodesics and Riemannian Laplace


So what does a straight line look like on a curved surface? Picture a ball moving on a surface without any external forces, like gravity, acting on it: if you give it a push, it slides along the straightest possible path on the surface -- such a path is called a *geodesic*. We describe a geodesic on the loss surface by its shadow on the floor, a curve $\boldsymbol{\alpha}(t)$ in parameter space. The curve is determined by two things: a differential equation that tells the ball how to accelerate at every moment, and an initial condition that tells it where to start and in which direction to move. Together, they form a so-called *initial value problem* (IVP). Starting from $\boldsymbol{\theta}^\ast$ with velocity $\tilde{\boldsymbol{v}}$, it reads

$$
  \ddot{\boldsymbol{\alpha}} = -\big(\dot{\boldsymbol{\alpha}}^\top \mathbf{H}(\boldsymbol{\alpha})\, \dot{\boldsymbol{\alpha}}\big) \operatorname{grad}\mathcal{L}(\boldsymbol{\alpha}), \qquad \boldsymbol{\alpha}(0) = \boldsymbol{\theta}^\ast, \quad \dot{\boldsymbol{\alpha}}(0) = \tilde{\boldsymbol{v}}.
$$

To keep the notation light, we drop the dependence on time: $\boldsymbol{\alpha}$ is the position at time $t$, dots are time derivatives, $\dot{\boldsymbol{\alpha}} := \frac{d}{dt}\boldsymbol{\alpha}(t)$, and $\mathbf{H}(\boldsymbol{\alpha})$ is the Hessian of the loss at the ball's current position. In words: whenever the ball moves through a region where the surface bends along its direction of motion, i.e. where $\dot{\boldsymbol{\alpha}}^\top \mathbf{H} \dot{\boldsymbol{\alpha}} \neq 0$, it is accelerated along the gradient by an amount set by that curvature. This bends its path in parameter space, so that the lifted path keeps following the surface.

This is the idea behind the *Riemannian Laplace approximation*<d-cite key="bergamin2023riemannian"></d-cite>: 
1. draw an initial velocity from a zero-mean Gaussian with the Laplace covariance, i.e. $\tilde{\boldsymbol{v}} \sim \mathcal{N}(\boldsymbol{0}, \mathbf{\Sigma})$ with $\mathbf{\Sigma} = (\mathbf{H} + \lambda\mathbb{I}_K)^{-1}$,
2. shoot a geodesic from $\boldsymbol{\theta}^\ast$ with initial velocity $\tilde{\boldsymbol{v}}$ by solving the IVP up to time $t = 1$, and keep its end point as the sample.

The sample paths now bend with the surface. Press "Sample" in the figure to see this and notice the difference to the straight-line samples previously shown. Then try changing the integration time: stop early and the samples barely leave $\boldsymbol{\theta}^\ast$, stop late and they move further up the walls of the loss.

Physically, a moving ball carries *kinetic energy*, which is the energy related to how fast it moves. For a unit-mass ball we measure this with the metric as

$$
  T(\boldsymbol{\alpha}, \dot{\boldsymbol{\alpha}}) = \tfrac{1}{2}\, \dot{\boldsymbol{\alpha}}^\top \mathbf{G}(\boldsymbol{\alpha})\, \dot{\boldsymbol{\alpha}},
$$

i.e. half the squared speed of the ball as measured on the surface. Since no forces act on the ball, its kinetic energy stays constant along a geodesic, so it never slows down, and nothing in its motion tells it when to stop. In the next two sections, we build on the kinetic energy to address this and obtain a method that comes to rest on the set of minima.

<details>
<summary>Geodesics and the Riemannian Laplace approximation</summary>

<p>A geodesic is a curve with zero tangential acceleration <em>on the manifold</em>. In parameter space coordinates, this is the equation $\ddot{\alpha}^k + \Gamma^k_{ij}\, \dot{\alpha}^i \dot{\alpha}^j = 0$, where $\Gamma^k_{ij}$ are the Christoffel symbols of the metric $\mathbf{G}(\boldsymbol{\alpha})$ at $\boldsymbol{\alpha}$. For the pullback metric of the loss surface, the Christoffel symbols simplify so much that the geodesic equations collapse to the closed form</p>

$$
  \ddot{\boldsymbol{\alpha}} = -\big(\dot{\boldsymbol{\alpha}}^\top \mathbf{H}(\boldsymbol{\alpha})\, \dot{\boldsymbol{\alpha}}\big) \frac{\nabla_{\boldsymbol{\theta}}\mathcal{L}(\boldsymbol{\alpha})}{1 + \lVert \nabla_{\boldsymbol{\theta}}\mathcal{L}(\boldsymbol{\alpha}) \rVert^2},
$$

<p>which only needs a Hessian-vector product with the velocity vector, never the full Hessian. The Riemannian Laplace approximation<d-cite key="bergamin2023riemannian"></d-cite> then defines its samples through the exponential map, which can be thought of as the Riemannian equivalent of the Euclidean addition operator:</p>

$$
  \boldsymbol{\theta} = \operatorname{Exp}_{\boldsymbol{\theta}^\ast}(\tilde{\boldsymbol{v}}) := \boldsymbol{\alpha}(1), \qquad \tilde{\boldsymbol{v}} \sim \mathcal{N}\big(\boldsymbol{0}, \mathbf{\Sigma}\big),
$$

<p>i.e. by solving the geodesic equations up to $t = 1$. In a flat space with the Euclidean metric $\mathbf{G}(\boldsymbol{\alpha}) = \mathbb{I}_K$, the Christoffel symbols vanish and the geodesic equations reduce to $\ddot{\boldsymbol{\alpha}} = \boldsymbol{0}$. Geodesics are then straight lines, $\boldsymbol{\alpha}(t) = \boldsymbol{\theta}^\ast + t\,\tilde{\boldsymbol{v}}$, so $\operatorname{Exp}_{\boldsymbol{\theta}^\ast}(\tilde{\boldsymbol{v}}) = \boldsymbol{\theta}^\ast + \tilde{\boldsymbol{v}}$ is exactly a sample from the standard Laplace approximation, and Riemannian Laplace is therefore a generalization of it. Close to $\boldsymbol{\theta}^\ast$, where the loss surface is nearly flat, the two approximately agree. Further away, the Riemannian samples follow the curvature of the loss. The time $t = 1$ is a convention inherited from the exponential map.</p>

<p><strong>Geodesics from energy.</strong> Geodesics can also be derived from energy, like all the dynamics in this note (see Appendix B of the paper). In classical mechanics, the path of the ball is determined by its <em>Lagrangian</em>, the kinetic minus the potential energy, i.e. $T - V$. The ball will follow the path that makes the time integral of $T - V$, the <em>action</em>, stationary. A free ball has no potential energy, $V = 0$, so its action is just</p>

$$
  S[\boldsymbol{\alpha}] = \int_{t_0}^{t_1} \tfrac{1}{2}\,\dot{\boldsymbol{\alpha}}^\top \mathbf{G}(\boldsymbol{\alpha})\,\dot{\boldsymbol{\alpha}}\; \mathrm{d}t.
$$

<p>The paths that make it stationary follow from the Euler–Lagrange equations, and for this action they are exactly the geodesic equations above. Since $T - V$ does not change explicitly with time, the total energy $T + V$ is conserved. With $V = 0$, the kinetic energy therefore stays at its initial value $\tfrac{1}{2}\tilde{\boldsymbol{v}}^\top \mathbf{G}(\boldsymbol{\theta}^\ast)\,\tilde{\boldsymbol{v}}$, revealing that a free ball never slows down.</p>

</details>

## Gravity to the rescue! Or not?

A geodesic only knows about the *shape* of the loss surface, not its *height*. To change this, we add *gravity* by letting the loss act as a *potential energy*,

$$
  V(\boldsymbol{\alpha}) = \kappa \big(\mathcal{L}(\boldsymbol{\alpha}) - \mathcal{L}^\ast\big),
$$

where $\mathcal{L}^\ast$ is the globally lowest loss and $\kappa > 0$ sets the strength of gravity. The potential energy is therefore never negative, and it is zero only at global minima. With this potential energy included, the ball is no longer free, and its motion is instead described by

$$
  \ddot{\boldsymbol{\alpha}} = -\big(\dot{\boldsymbol{\alpha}}^\top \mathbf{H}(\boldsymbol{\alpha})\, \dot{\boldsymbol{\alpha}} + \kappa\big) \operatorname{grad}\mathcal{L}(\boldsymbol{\alpha}).
$$

Compared with the geodesic equations, there is one new term, namely $-\kappa \operatorname{grad}\mathcal{L}(\boldsymbol{\alpha})$, which acts as a gravitational pull on the ball: near any minimum, global or local, a step away from the set of minima increases the potential energy, so the ball is pulled back towards the set. The curvature and gravity terms both act along the Riemannian gradient, and setting $\kappa = 0$ gives back the geodesics. Note also that the global minimum value $\mathcal{L}^\ast$ has disappeared in the ODE: only the gradient of $V(\boldsymbol{\alpha})$ enters the dynamics, so we never need to know the globally lowest loss to simulate the ball.

To see how the updated dynamics behave, press "Launch" in the figure. The ball is pulled towards the set of minima, but it oscillates around it without ever coming to rest: the system conserves energy, so the total energy $H = T + V$ (not the Hessian $\mathbf{H}$) stays constant. Even in this toy setting, the solver can become numerically unstable for some initial velocities. We show these failed samples with <svg class="fail-mark" viewBox="0 0 14 14" aria-label="cross marker"><path class="edge" d="M3 3L11 11M11 3L3 11"/><path class="core" d="M3 3L11 11M11 3L3 11"/></svg>.

In a flat parameter space, $\mathbf{G}(\boldsymbol{\alpha}) = \mathbb{I}\_K$, the curvature term disappears and the Riemannian gradient becomes the ordinary gradient, so the dynamics reduce to $\ddot{\boldsymbol{\alpha}} = -\kappa \nabla\mathcal{L}(\boldsymbol{\alpha})$, a ball rolling under gravity alone. This results in the ball heavily swinging back and forth *across* the set of minima, whereas on the curved loss surface, the geometry steers the ball *along* the set of minima while gravity keeps it close. Switch *Parameter space* in the figure to compare the two. In neither case does the ball come to rest.


<details>
<summary>Loss as potential energy, and the equation of motion</summary>

<p>The equations of motion under a gravitational pull follow from the same principle as the geodesics, now with $V \neq 0$: the ball follows the path that makes the action, the time integral of $T - V$, stationary. In coordinates, the Euler–Lagrange equations read</p>

$$
  \ddot{\alpha}^k + \Gamma^k_{ij}\, \dot{\alpha}^i \dot{\alpha}^j = -\big(\mathbf{G}(\boldsymbol{\alpha})^{-1} \nabla V(\boldsymbol{\alpha})\big)^k,
$$

<p>i.e. the geodesic equations with the force of the potential on the right-hand side. For the pullback metric of the loss surface, this simplifies to the closed form in the main text. As $T - V$ does not depend explicitly on time, the total energy $H = T + V$ is conserved along every path and $\dot{H} = 0$. A ball launched from $\boldsymbol{\theta}^\ast$ with kinetic energy $T_0$ therefore keeps the total energy $H = T_0 + V(\boldsymbol{\theta}^\ast)$ for all time, where $V(\boldsymbol{\theta}^\ast) = 0$ only if $\boldsymbol{\theta}^\ast$ is a global minimum. The ball can trade speed for height, but never comes to rest.</p>

</details>

## Braking at the right time

To make the ball stop, energy has to leave the system, which we do by adding *friction*. Friction is a force that acts against the motion of the ball, proportional to its velocity and scaled by a friction coefficient $\eta(\boldsymbol{\alpha}, \dot{\boldsymbol{\alpha}}) > 0$. This adds one term to the dynamics,

$$
    \ddot{\boldsymbol{\alpha}} = -\big(\dot{\boldsymbol{\alpha}}^\top \mathbf{H}(\boldsymbol{\alpha})\, \dot{\boldsymbol{\alpha}} + \kappa\big) \operatorname{grad}\mathcal{L}(\boldsymbol{\alpha}) - \eta(\boldsymbol{\alpha}, \dot{\boldsymbol{\alpha}})\, \dot{\boldsymbol{\alpha}}.
$$

As a consequence, the total energy now decreases whenever the ball moves,

$$
  \frac{\mathrm{d}}{\mathrm{d}t} H(\boldsymbol{\alpha}, \dot{\boldsymbol{\alpha}}) = -2\, \eta(\boldsymbol{\alpha}, \dot{\boldsymbol{\alpha}})\, T(\boldsymbol{\alpha}, \dot{\boldsymbol{\alpha}}) \leq 0,
$$

with equality only when the ball stands still, $\dot{\boldsymbol{\alpha}} = \boldsymbol{0}$. As the energy keeps decreasing while the ball moves, the ball eventually comes to rest, and a ball can only rest where nothing pulls it any further, i.e. at a stationary point of the loss. Such a point could in principle also be a saddle point. However, if the loss has the so-called *strict saddle property*, every saddle point has at least one direction in which the loss curves downwards. A ball resting there is like a ball balanced on a mountain pass: the slightest nudge makes it roll off, so it almost never ends up there. With friction, the ball therefore approaches the set of minima. In theory, it only reaches it in the limit, but we can stop the simulation once the ball has (nearly) come to rest, instead of at a time chosen heuristically.

The choice of friction decides *where* on the set of minima the ball ends up. A constant $\eta$ brakes equally in all situations, also when the ball moves along the set of minima, which is exactly the motion we would like to keep. $\text{DiMS}$ instead uses a friction that grows with the square root of the kinetic energy. Writing out the kinetic energy shows what this means,

$$
  T(\boldsymbol{\alpha}, \dot{\boldsymbol{\alpha}}) = \tfrac{1}{2}\, \lVert \dot{\boldsymbol{\alpha}} \rVert^2 \big(1 + \lVert \nabla\mathcal{L}(\boldsymbol{\alpha}) \rVert^2 \cos^2\omega\big),
$$

where $\omega$ is the angle between the ball's velocity and the gradient of the loss. For a given speed, the friction is therefore largest when the ball moves along the gradient, up or down the walls of the loss, and least along level sets, where the loss does not change. The ball is thus slowed down most when it changes the loss. Moreover, as the ball loses energy, its friction decreases too, so in our experiments it travels further than with a constant friction of the same initial strength. The full dynamics are summarized below, where $\eta_0 > 0$ sets the strength of the friction and the small constant $\eta_{\min} > 0$ keeps some friction when the ball is nearly at rest.

<details>
<summary>The $\text{DiMS}$ friction and the guarantees it gives</summary>

<p>The friction $\eta(\boldsymbol{\alpha}, \dot{\boldsymbol{\alpha}})$ depends on time only through the state of the ball, so the dynamics form an <em>autonomous</em> system. This is what makes the convergence analysis in the paper<d-cite key="jacobsen2026dims"></d-cite> possible.</p>

<p>Under mild assumptions on the loss, the paper shows that the friction always removes energy, and that the ball converges to rest at a stationary point of the loss, which is almost surely a minimum. Along the way, the loss never rises by more than the initial kinetic energy allows. Before coming to rest, the ball travels a guaranteed distance on the loss surface that grows as $\eta_0$ decreases, at the cost of a longer run. Finally, the small floor $\eta_{\min} > 0$ ensures that the ball comes nearly to rest within a bounded time, so that the simulation can be stopped. See Section 3 of the preprint for the precise statements and their assumptions.</p>

<p><strong>In the figures,</strong> we use $\kappa = 1$, $\eta_0 = 1$ and $\eta_{\min} = 0.1$. The constant friction is matched to $\text{DiMS}$ at launch, $\eta = \eta_0\sqrt{T_0} + \eta_{\min}$, where $T_0$ is the initial kinetic energy.</p>

</details>

## From one ball to an ensemble

We have now described all the elements of the $\text{DiMS}$ sampler. Starting from a single trained model $\boldsymbol{\theta}^\ast$, we draw an initial velocity $\tilde{\boldsymbol{v}} \sim \mathcal{N}(\boldsymbol{0}, \mathbf{\Sigma})$ from the Laplace approximation, launch the ball with the $\text{DiMS}$ dynamics, and keep the endpoint where it comes to rest as a sample. Repeating this gives an ensemble of models on the set of minima.

In the figure, "One sample" gives the same draw $\tilde{\boldsymbol{v}}$ to all five methods (Laplace, Riemannian Laplace, gravity without friction, constant friction and $\text{DiMS}$), and the buttons below add many samples per method. The strips under the plot show how the samples spread across and along the set of minima.

<aside>
<strong>A 2D artefact.</strong> In 2D the set of minima is a single curve, and the valley around it is least steep at $\boldsymbol{\theta}^\ast$. Balls that keep swinging across the valley therefore tend to drift back towards $\boldsymbol{\theta}^\ast$. In a real network the set of minima has many more directions, so we expect this pull to be much weaker.
</aside>

## Takeaways

- **The minima form a set,** and a trained model is only one point on it.
- **Laplace-type methods cannot follow it,** because they are fixed around a single point or need a heuristically-chosen stopping time.
- **$\text{DiMS}$ rolls a ball on the loss surface** with gravity and a friction that brakes when it moves up- or downhill, so it comes to rest on the set of minima.
- **Many launches give an ensemble** of models that all fit the data well.

The figure shows the loss surface from the beginning of the note, now with a whole $\text{DiMS}$ ensemble launched from $\boldsymbol{\theta}^\ast$. For the full details, see the paper<d-cite key="jacobsen2026dims"></d-cite> and the code linked at the top of the note.
